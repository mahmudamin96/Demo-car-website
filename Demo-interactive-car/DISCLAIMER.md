# Disclaimer — experimental and learning project

This repository is a **personal experiment and learning exercise**. It is not a
commercial product, a production website or an official site for any company.

## What this project is

- A local study of how an interactive, media-driven web page is built and run:
  React, TypeScript, Vite, hover video playback, CSS transitions and responsive layout.
- A place to try changes (renaming, swapping media, toggling features) and learn
  from the results.
- Provided **as is**, without any warranty, support or guarantee that it works
  for any particular purpose.
